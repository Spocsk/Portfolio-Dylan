# Report Template

Use this structure exactly unless the user asks for another format.

## Résumé exécutif

Write 8 to 12 lines maximum. State:

- project type
- strongest verified strengths
- biggest verified weaknesses
- whether the issue is mainly technical, semantic, authority-related, or off-site
- whether a live domain was verified or not
